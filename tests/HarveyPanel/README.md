# Проверки интерфейса «План Харви»

Консольные проверки без загрузки сохранения и без внешних NuGet-пакетов.
Используют фактически установленную StardewUI Continued и собранный Debug DLL Core.

Из каталога `HarveyOverhaulCore`:

```powershell
dotnet build --no-restore -p:EnableModDeploy=false -p:EnableGameDebugging=false
dotnet restore tests/HarveyPanel/HarveyOverhaulCore.UiChecks.csproj --ignore-failed-sources
dotnet run --project tests/HarveyPanel/HarveyOverhaulCore.UiChecks.csproj -- "D:\Stardew Valley Mymods"
```

Путь игры задаётся свойством `GamePath` тестового проекта, а для загрузки
зависимостей во время выполнения — переменной `STARDEW_GAME_PATH`.

Проверяются пустой план, готовые и ожидающие действия, ежедневные правила,
дубли директив, справочные записи, предупреждения, срочные назначения и
нарушения с потерей дня лечения. Отдельно проверяется совместимость с
`FailureReason`, который присылает мод травм.

Каждый SML-файл разбирается парсером установленной StardewUI. Проверяются
имена свойств настоящих виджетов, существование включаемых представлений,
свойства моделей с учётом `*repeat` и `*context`, обработчики событий и
переходы к родительскому контексту. Также проверяются размеры окна для
1920×1080, 1280×720, 960×540, 640×480 и 480×360.

Это проверки структуры и поведения модели; они не заменяют визуальный
просмотр в игре. При проверке в игре нужно открыть план с пустым состоянием,
активной травмой, стрессом и нарушением режима; проверить раскрытие
пояснений, выполненных пунктов, справки, работу мышью и геймпадом.
